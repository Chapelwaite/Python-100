# ExpenseTrackerCLI

ExpenseTrackerCLI is a Python terminal app for tracking daily expenses and saving them in a JSON file.

## Features

- Add expenses
- List all expenses
- Delete expenses
- Track amount, category, note, and date
- Show total spent
- Show category summary
- Show monthly summary
- Search expenses
- Saves data in JSON
