# TodoVaultCLI

TodoVaultCLI is a Python terminal todo manager that lets users add, view, complete, delete, search, and save tasks.

## Features

- Add tasks
- List all tasks
- Mark tasks as completed
- Delete tasks
- Search tasks
- Priority system: low, medium, high
- Task statistics
- Saves tasks in JSON file
